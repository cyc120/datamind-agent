下载本版本原 DXF

文字边界和字体近似；原图显示原始提取关联。完成关联复核后，可在「尺寸核验」显式绑定本地测量并申请独立使用批准。

登记本地图纸或新版本

素材区中的文件由本地管理员准备；仅支持当前限定 DXF 格式。系统固定源文件和版本，失败不生成图纸记录。

Dimension Evidence

尺寸核验

登记测量，明确绑定已复核的标注，再由独立账户批准使用。单次比较保留原值与版本，不代表制造授权或整体质量合格。

测量与绑定

登录后可查看尺寸记录。

1 · 登记本地测量

管理员准备单条测量 JSON 素材，源文件声明测量 ID、记录版本与生产范围。登记固定源文件内容；改版须使用当前基线。

输入测量 ID 后读取基线。

2 · 显式绑定标注

仅绑定当前测量和当前图纸中已确认的关联。批次、工序及工艺版次来自所选测量，图纸版次单独保留。

输入绑定 ID 后读取基线。

3 · 使用批准与当前核验

批准人须同时独立于绑定登记人和关联复核人。图纸、测量或复核变化后须重新核对；撤销会阻断后续比较。

4 · 核验历史回放

回放显示当时的版本、批准与核验结果。旧快照不会因后续撤销而改写，当前能否使用以上方核验为准。
