# 私有 PDF 知识版本发布审查记录

2026-10-07，API 0.16.0。范围为已认证快照的私有索引发布、冻结计划 outbox 恢复与固定历史切片读取。主代理整合 API/隔离回归/真实模型 CLI 与说明，分工代理实现并验证 SQL 控制面、向量 adapter 和 HTTP 边界；最终全套由主代理运行。

## 关键检查与修复

- Qdrant 预写不是发布。首次计划先落 outbox，向量操作不持 DB 事务，真实逐点读回后才允许短事务 CAS 提交知识头/结果/状态。提交 claim 绑定实际确认的完整计划摘要，禁止确认后数据库换计划。
- 文档 advisory lock 与快照登记兼容，原 owner/当前角色与会话在账户、发布请求和知识头行锁等待后用新时钟重验；token/租约在 SQL 写入时再次检查。已确认 pub/head 行等待期间自然过期、旧 owner 延迟完成、全局两个 running 槽、回滚/CAS 冲突、失效身份落失败和不确定提交恢复。
- Qdrant 1.12.4 真实 REST 测试揭示 bbox float64 回读 1 ULP 差，内存模式没有覆盖。保留来源 chunk 原值，payload 使用精确 bbox_f64_hex 字符串；512 维 Dot float32 实际字节核验继续严格，无容差放行。
- 新独立向量实例只映射 loopback REST 并需 key；生产 factory 对无 key 服务拒绝访问，只连接显式私有配置。所有新 API admin/CSRF/同源/no-store，最终响应前再次查询权限；列表和元数据不假称文件/点已核验，历史 chunks 才完整验证。
- HTTP 不运行嵌入，实际 CLI 失败返回 exit 1；原请求/失败项恢复保留 owner、基线与计划，已有冻结计划在缺失模型缓存时仍可重放。旧公开 RAG、知识表/事实/审批与演示向量没有接入新私有数据。

## 当前边界

已发布点丢失/变更会拒绝读取，但当前没有自动修复已发布存储、孤立回收、解析/OCR/upload 队列或私有模型问答。全 worker 两槽和单次 5 秒 DB 锁等待不是硬 CPU/内存隔离或请求 deadline。校验绑定核验时刻的字节，可信操作者仍可管理底层数据库/存储；哈希不是认证签名。私有 publication 状态不代表公开知识、来源权威或业务批准。
