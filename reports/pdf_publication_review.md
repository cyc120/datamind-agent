# 私有 PDF 快照登记审查记录

2026-10-07，API 0.15.0。范围为已封存原生 PDF 的认证登记、当前头 CAS、原请求恢复和固定历史读取。服务与 HTTP 测试由独立代理实现/核查，最终由主代理运行完整隔离回归；旧摄取、原 PDF 准备和事实/审批逻辑保持不变。

## 审查修复

- 文件核验可能超过中间件的初始认证时刻。新接口在结果构建、文件 bytes 捕获后再次检查真实 admin 会话；对详情、列表/历史、PDF/PNG/bundle 和已提交 POST，新增真实数据库撤销/降权边界。POST 最终认证失败不等于事务回滚，原请求仍可恢复已登记版本。
- PostgreSQL 获取账户/会话行锁时可能等待。登记不再依赖等待前评估的过期谓词，而是在获取两类共享行锁后以独立 SQL 的新时钟重验启用、撤销、过期和角色。实际未改字段的账户排他锁等待期间过期也被拒绝。

## 并发与证据核查

文档、请求、attempt 锁排序，版本和当前指针同事务提交；同头竞争仅一方成功，不同文档可以推进。请求 owner/规范载荷、attempt 唯一消费、当前前版/源 SHA 和幂等重放均有数据库测试。事务回滚保留 prepared 文件，锁超时返回稳定 503，原请求可重试。

固定历史读取核对数据库证据与完整 prepared 快照。实际返回文件捕获后再核对大小/摘要，避免验证后改动的内容被返回。列表/历史只核对元数据，明确文件完整性未检查。新表未授权 readonly/PUBLIC，不通过旧文档/RAG 暴露登记数据。

## 验证结果和限制

服务初始 25/25、最终 27/27，HTTP 初始 15/15、最终 19/19，日志分别保留。完整隔离回归 **338/338，失败 0、错误 0、退出码 0**；报告见 `pdf_publication_regression.txt` 和 `pdf_publication_verification.json`。原库计数未变，新表未在原库创建，测试副本不复制私有登记行或模型配置，临时账号/产物/库已清理。准备模块和 CAD/尺寸/DXF 的 11/13/8 个冻结摘要未改；技术说明书 §18.2–18.30 历史记录保持原文。

两个验证槽作用于单服务进程，5 秒 lock_timeout 作用于每次数据库锁等待；当前没有完整请求 deadline、跨进程资源总量或原生 CPU/内存硬隔离。摘要证明核验/捕获时的本地字节，不能阻止可信数据库/文件系统所有者修改记录或忽略文件锁，也不是认证签名。

HTTP 没有执行原生解析、OCR、嵌入或外部模型调用，没有新增 PDF 上传/worker/页面。登记保持 `indexed=false`、`knowledge_visible=false`、`source_authority_verified=false`，不等于知识库发布、来源权威或业务批准。上述结果是合成边界/集成验证，不是识别准确率或工厂盲测。
