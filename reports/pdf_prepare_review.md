# 原生 PDF prepare 审查记录

日期：2026-10-07。范围为离线原生 PDF 准备模块及其合成边界测试；不包括认证发布、索引或 OCR。

独立只读审查发现并复现了三个边界缺口，修复后再次检查：

- 以阻塞读取方式打开 FIFO 会在常规文件校验前挂起。现使用非阻塞打开并拒绝非常规文件，源与已封存产物均受同一约束。
- 原生文本坐标未旋转，而页面图像已旋转。现记录原生/渲染坐标系、页旋转及裁剪信息，并校验坐标变换；实际 0/90/180/270 度与非零裁剪页验证通过。
- 仅查 `get_images` 会漏 inline 图像和超大 SMask/Mask。现同时检查资源图像、递归遮罩及实际显示图像，采用保守重复累计而不通过图像解码哈希去重；真实 PDF 超限在渲染前拒绝。

另用真实空 user password 加密 PDF 验证了拒绝。独立进程并发封存、相同请求重放、版本化 ID、摘要链与路径拒绝由最终 31 项专项覆盖；实际 CLI 的 8 项行为验证另列。模块没有导入旧摄取、数据库、Qdrant 或模型配置模块，不更新知识库。
