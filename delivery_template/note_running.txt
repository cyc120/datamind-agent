提示（中文）：
  * 本窗口就是服务窗口，请保持打开；关掉它服务就停了。上面那一串英文提示
    与这里说的是同一件事 —— 启动脚本本身必须保持纯英文，原因见交付文档。
  * 服务日志：uvicorn 的实时日志显示在另一个标题为 "DataMind Agent service log"
    的窗口里，同时也会写进 data\logs\api_console.log。排查问题时请把这个文件发给我们。
  * 问答要真的调用大模型：请在页面左侧「模型接入」里填入你的 API Key 与模型名
    并保存（保存在预置数据库里，不会写到包外）。没有配置时问答会返回
    MODEL_KEY_MISSING 的提示，这是设计行为，不是故障。
  * 停止服务：在本窗口按任意键，或双击本目录下的 stop.bat。
    那个日志窗口可以直接关掉，不影响服务。
  * 只监听 127.0.0.1，不对局域网开放；首次启动如遇杀毒 / 防火墙弹窗，选择「允许」即可。
