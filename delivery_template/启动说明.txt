========================================================================
 启动说明（给审核老师 / 第一次使用的人）
========================================================================

一、这是什么
    DataMind Agent 的完整可运行版本，打成便携包。
    你不需要安装 Docker、Python、PostgreSQL、Qdrant 中的任何一个：
    这些运行时都已经在这个文件夹里了。

二、第一次启动（预计 1~2 分钟）
    1. 解压压缩包到任意一个普通文件夹，例如 D:\DataMindAgent_Demo
       建议不要放在 C:\Program Files、C:\Windows 或网盘同步目录里。
    2. 双击 run.bat。
    3. 屏幕上会依次出现：
         [1/6] 端口检查
         [2/6] 启动 PostgreSQL
         [3/6] 启动 Qdrant 向量库
         [4/6] 启动 Web 服务
         [5/6] 等待服务就绪
         [6/6] 打开浏览器
    4. 浏览器自动打开 http://127.0.0.1:8000/ ，就可以提问了。

    如果浏览器没有自动打开，手动在浏览器地址栏输入：
         http://127.0.0.1:8000/

三、演示数据是预置好的，不用等
    数据库（演示零售库、Chinook、元数据库）和向量库在打包时就初始化并
    摄取完毕，所以启动后可以直接用：文档已经在库里，向量检索也是现成的。
    启动阶段只做「起服务」，不做建库、迁移、摄取。

四、提问要接大模型，请先填 Key（本包不预置密钥）
    页面左侧 →「模型接入」→ 填写：
       接口地址：https://api.deepseek.com/v1  （或你用的兼容服务地址）
       模型名称：deepseek-chat                （或你用的模型）
       API Key ：sk-...
    保存后即可正常提问。

    也可以预先写在文件里：复制 data\model_config.env.example 为
    data\model_config.env，填好后重新启动 run.bat。
    ※ 填入真 Key 后请勿把整个文件夹转发他人。

五、怎么停止
    * run.bat 窗口按任意键 → 全部停止；
    * 或双击 stop.bat；
    * 或直接关闭 run.bat 的窗口（后台看门狗会把数据库/向量库一起收掉）。

六、常见问题
    Q: 提示「端口 8000 / 55432 / 56333 已被占用」
    A: 说明上一次没有退干净，或者另有程序占用。先双击 stop.bat；
       仍然不行就重启电脑。这三个端口是刻意选的非默认端口，
       正常情况下不会和你机器上已装的 PostgreSQL(5432)/Qdrant(6333) 冲突。

    Q: 杀毒软件 / 防火墙弹窗
    A: 选「允许」。程序只监听本机回环地址 127.0.0.1。

    Q: 提示「交付包不完整」
    A: 多半是解压时被杀毒软件拦截，或者只解压了部分文件。
       请把整个压缩包重新完整解压后再双击 run.bat。

    Q: 网页打开了但提问报模型错误
    A: 说明还没配 Key，或 Key/模型名不对。见上面第四节。

    Q: 想看看它到底连了什么
    A: 命令提示符里执行
         powershell -NoProfile -ExecutionPolicy Bypass -File tools\dmstack.ps1 -Action status
       可以看到三个服务的运行状态和 /health 的返回。

七、这个包不做什么
    * 不安装系统服务、不写注册表、不改系统 PATH；
    * 不开局域网访问（只绑 127.0.0.1）；
    * 不预置任何大模型密钥；
    * 不依赖 Docker：即便你机器上装了 Docker 也完全用不到它。
